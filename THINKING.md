# Thinking

Thinking is the asset. Code is just a rendering of ideas at a point in time. It gets rewritten. It gets thrown away. The reasoning behind it is what lasts.

The question matters more than the generation. If the reasoning was realised at the right moment, you can stand on it to reason higher. Each level of understanding becomes the foundation for the next.

Think more, code less. Not because code doesn't matter, but because good thinking produces simpler code. You end up at higher scales with less complexity underneath.

Code is becoming ephemeral. It's cheaper to produce, faster to rewrite, sometimes used once and discarded. The ideas it encodes are the durable part.

Agents are ephemeral too. They spin up, they do work, they disappear. A browser tab closes. An IDE restarts. The coordination layer — the space where they find each other — is the thing that persists.

Software doesn't need to be precious. Learn the basics well. Understand them deeply. Then stand on top of them.
